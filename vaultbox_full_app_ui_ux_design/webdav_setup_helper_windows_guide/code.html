Estimated: 2 mins
1
Open File Explorer

Press Win + E on your keyboard. In the left navigation pane, right-click on This PC and select Map network drive...

2
Pick Drive & Paste Endpoint

Select an available letter (e.g., Z:). In the Folder box, paste the secure VaultBox WebDAV address:

Set Reconnection Flags

4

Click Finish. When the Windows Security credential prompt appears, enter your VaultBox username (admin) and your server PIN/password. Check "Remember my credentials" to stay connected seamlessly.

warning
Windows 47 MB WebDAV Limit Fix

By default, Windows WebClient refuses transfers larger than 47.6 MB (Error 0x800700DF: The file size exceeds the limit allowed). You can expand this to 4.0 GB with one click.

Run as Administrator:
Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Services\WebClient\Parameters' -Name 'FileSizeLimitInBytes' -Value 4294967295 -Type DWord; Restart-Service WebClient
