Setup Guide by Platform Interactive Guide
Windows File Explorer Native Mount
1

Open Windows File Explorer (Win + E) and click This PC in the left sidebar.

2

In the top horizontal ribbon, select Map network drive (or press Alt + T then M).

3

Choose a Drive Letter (e.g. V: for VaultBox), then paste your endpoint into the Folder field:

https://vaultbox.local:8443/webdav
4

Check "Connect using different credentials" and click Finish.

5

When the Windows Security dialog appears, enter username admin and your App Access Token as password.

help_outline Windows WebClient Service Note

If Windows displays "The folder you entered does not appear to be valid", ensure Windows WebClient service is running and install the VaultBox Root Certificate or run the auto-patch script below.

laptop_macmacOS Finder
Connect to Server (Cmd + K)
1

Switch to Finder or click on the desktop, then press Cmd + K (or choose Go > Connect to Server… from the top menu bar).

2

In the Server Address field, enter the secure WebDAV URL:

https://vaultbox.local:8443/webdav

Clicking the + button saves it to your Favorite Servers for quick 1-click mounting.

3

Click Connect. When prompted for credentials, select Registered User.

4

Enter Name: admin and Password: your App Access Token. Check "Remember this password in my keychain" for seamless auto-reconnect.

5

VaultBox now mounts on your macOS Desktop and Finder sidebar under Locations just like an external SSD or Apple File Share.

folder_specialmacOS Finder WebDAV & ._ File Cache Tip

macOS Finder creates hidden ._ resource fork files by default. VaultBox automatically intercepts and shields these system metadata files in a sandbox cache to preserve your phone storage cleanliness.

terminalLinux (GNOME / CLI)
Nautilus / mount.davfs
Section A · GUI (GNOME Nautilus / Dolphin)
1

Open Files (Nautilus) and click + Other Locations at the bottom of the left sidebar.

2

In Connect to Server, enter the secure WebDAV URL and click Connect:

davs://vaultbox.local:8443/webdav

Note: You can also use https://vaultbox.local:8443/webdav depending on desktop environment.

3

Enter Username: admin and Password: your App Access Token. Select Remember forever in GNOME Keyring.

Section B · CLI / Terminal & fstab (Power Users)
4

Install davfs2 driver and mount directly to your filesystem:

# Install & Mount

sudo apt install davfs2

sudo mount -t davfs https://vaultbox.local:8443/webdav /mnt/vaultbox

infoLinux Permissions & davfs2 Cache Tip

To auto-mount without sudo, add your user to the davfs2 group and store credentials in ~/.davfs2/secrets. VaultBox supports standard HTTP Keep-Alive and WebDAV locking.
